# Colour Match – Python Game

This project is a simple little colour-matching game I created for Assessment 2 of the Foundations of Programming and Software Engineering module. The aim was mainly to show that I can work with GitHub properly, not to build anything too complicated.

---

# How the Game Works
The game shows a colour name and a few coloured buttons. The player just picks the button that matches the word. If the choice is right, a message pops up saying so. If not, it lets the player try again. It’s a very basic, child-friendly game.

---

# How to Run It
To run this game, you just need Python 3 installed on your device (most laptops already have it). Then:

1. Save the file called `color_match.py` from GitHub onto your device in a folder you can find easily, like Desktop or Documents.
2. Open the file in your preferred IDE (VS Code, PyCharm, or any coding app you use).
3. Open your terminal or command prompt.
4. Use `cd` to move into the folder where the file is saved. For example, if it's on your Desktop:
   cd Desktop
5. Once you’re in the right folder, run:
   python color_match.py
6. The game window will pop up and you can start playing straight away.
